# Version 18

Released 2026-10-21, deploying the merge of release pull request #372 into `main`. The changes below are what this release adds to the previous deploy (7332833, version 17).

## Changes

- API: the trusted proxy ranges come from `TRUSTED_PROXIES`, which each environment sets to its own `backend` subnet (`172.27.0.0/24` in production). So production no longer trusts the dev backend subnet, and the API refuses to start in production without the setting (#371, closes #353).
- Observability: the container memory alert counts RSS, not the page cache, so Elasticsearch's cache no longer sets it off (#371, closes #349).
- Dependencies: vite 8.3.5, for 3 `launch-editor` advisories (#371, closes #370).
- Tooling: local image builds work with any Buildx version, a new worktree keeps the passwords from `.env`, the guard tests no longer stall the pre-push gate, and the naming and constants checks work on Windows (#371, closes #357, #361, #365, and #348).
- Web: the Sentry source map warning is gone since `@sentry/astro` 11.8.0, which fixed the bug we reported (#371, closes #298).

## Release steps

A plain deploy. It recreated Grafana for the changed alert rule.
