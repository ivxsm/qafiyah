# Version 19

Released 2026-10-22, deploying the merge of release pull request #377 into `main`. The changes below are what this release adds to the previous deploy (76ceffa, version 18).

## Changes

- Web: share a poem or a poet from one sheet (Telegram, WhatsApp, Facebook, and X), copy a whole poem from the poem toolbar, and get the poem link at the end of copied verses (#369, refs #304).
- Web: the share icon next to the poet name grows with the name on wide screens, sits closer to it, and lines up with its letters (98a0c31).
- Development: `bun run dev` restores the 100-poem sample, unless `--dump <folder>` asks for a full dump (#378, closes #373).
- Development: the local worktree support is gone (#378, closes #374).
- Docs: the README and the docs describe the MCP server, and the README lists snapshot 0046 (#378, closes #375).
- Builds: the Rust images build their dependencies in a cached layer of their own with cargo-chef, and release builds use thin LTO (#378).

## Release steps

A plain deploy. Its first build makes each Rust image's dependency layer once.
