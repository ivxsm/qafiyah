# Version 17

Released 2026-10-21, deploying the merge of release pull request #368 into `main`. The changes below are what this release adds to the previous deploy (1a83deb, version 16).

## Changes

- Repository: the git history no longer holds the old data snapshots (stage 3 of #359). A fresh clone is about 7 MB, down from 6.9 GB. Every commit SHA from before 2026-10-21 changed, and the changelogs cite the new ones. Clones and forks made before 2026-10-21 must be made again, or reset to the new branches before they push (#367, closes #366).

## Release steps

A plain deploy. Before it, the server's checkout moved to the rewritten history in place, with no container restart.

## Follow-ups

- Fork pull request #340 was closed by GitHub during the rewrite. Its rebased commits wait on the branch `share-buttons-rebased` for a new pull request.
